# Other UX skills and borrowed approaches

Use when: comparing approaches or sources of existing UX skills, or deciding what to load for mobile platform detail.

GitHub stars and licences checked via the GitHub API, 2026-11 (stars rounded). They are repository stars. The list mixes popular tools with sets relevant to interaction design.

| Repository | Stars | Licence | What it covers and how it is used here |
| --- | ---: | --- | --- |
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | ~152k | MIT | Broad base of interface patterns. Source of the approach of checking concrete interactions on real devices and covering responsiveness, long text, cancel and accessibility. |
| [Taste Skill](https://github.com/Leonxlnx/taste-skill) | ~120k | MIT | Art direction and in-browser checks. Useful: verify the working interface with real content. |
| [Impeccable](https://github.com/pbakaus/impeccable) | ~114k | Apache-2.0 | Interface critique, audit and polish. Principle used: inspect a concrete screen or flow and rank problems by consequence. |
| [AI Design Skills](https://github.com/elayadesign/ai-design-skills) | ~16k | MIT | Visual skills incl. landing pages. For UX the takeaway is checking hierarchy on realistic content. |
| [Apple Design Skill](https://github.com/dickwu/apple-design-skill) | ~3.7k | none declared | Review against Apple HIG. Ideas only (no licence): emphasis on system patterns and per-platform element behaviour. |
| [UX/UI Agent Skills](https://github.com/plugin87/ux-ui-agent-skills) | ~3.2k | MIT | Heuristic review, prototyping, accessibility, user tests, microcopy tied to one flow and a result check. |
| [Design Skills](https://github.com/cuellarfr/design-skills) | ~129 | MIT | Similar scope; links heuristics and UX laws with navigation, research, accessibility and text analysis. |

These repositories are sources of approaches. This skill works without installing them.
