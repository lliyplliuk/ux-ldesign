# Android / Material 3

Use when: reviewing or designing a native Android screen, or a cross-platform app shipping to Android. iOS counterpart and shared cross-platform rules: [mobile-ios.md](mobile-ios.md). Checked 2026-11-21 against developer.android.com; Material pages (m3.material.io) need JavaScript and could not be fetched, so Material-only values are marked.

| Area | Rule | Check | Source |
|---|---|---|---|
| Targets | Touch targets are at least 48 dp. | Accessibility Scanner or layout inspector on all clickable views. | [Core app quality](https://developer.android.com/docs/quality-guidelines/core-app-quality), [Compose defaults](https://developer.android.com/develop/ui/compose/accessibility/api-defaults) |
| Spacing | Touch targets at least 48x48 dp, separated by 8 dp of space or more (Google guidance says "consider", so treat as a strong recommendation). | Measure gaps in the design file. | [Android accessibility help: touch target size](https://support.google.com/accessibility/android/answer/7101858) |
| Edge-to-edge | Draw behind system bars with transparent or translucent bars, handle WindowInsets so content is not obscured, and avoid interactions under gesture-navigation insets. Apps targeting SDK 35 on Android 15+ are edge-to-edge by default. | Test 3-button and gesture navigation, display cutouts and IME. | [Edge-to-edge](https://developer.android.com/develop/ui/views/layout/edge-to-edge), [System bars](https://developer.android.com/design/ui/mobile/guides/foundations/system-bars) |
| Back | Support the system back button and back gesture; no custom on-screen back prompt. Predictive back previews the destination; intercept back only via AndroidX/OnBackInvokedCallback, not KEYCODE_BACK. | Gesture-nav back-to-home preview animates. | [Core app quality](https://developer.android.com/docs/quality-guidelines/core-app-quality), [Predictive back](https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture) |
| Navigation | Navigation bar when width or height is compact; navigation rail otherwise; drawer is the third variant. A rail holds three to seven destinations. A navigation bar holds three to five destinations. | Resize window through compact, medium, expanded. | [Adaptive navigation](https://developer.android.com/develop/ui/compose/layouts/adaptive/build-adaptive-navigation), [NavigationRail](https://github.com/material-components/material-components-android/blob/master/docs/components/NavigationRail.md), [BottomNavigation](https://github.com/material-components/material-components-android/blob/master/docs/components/BottomNavigation.md) |
| Adaptive | Use window size classes (width: compact <600, medium 600, expanded 840, large 1200, extra large 1600 dp; height: medium 480, expanded 900 dp). Optimise expanded first when starting from compact. Keep functional parity across orientations and fold states, no letterboxing. | Test folded, unfolded, split-screen, rotation without state loss. | [WindowSizeClass](https://developer.android.com/reference/kotlin/androidx/window/core/layout/WindowSizeClass), [Window size classes](https://developer.android.com/develop/ui/compose/layouts/adaptive/window-size-classes), [Core app quality](https://developer.android.com/docs/quality-guidelines/core-app-quality) |
| Colour | Dynamic Color (Android 12+) derives the scheme from wallpaper; keep a static fallback. Contrast 4.5:1 small text (under 18 pt, or 14 pt bold), 3:1 large text and graphics. Support light and dark themes. | Wallpaper change; dark theme; contrast tool. | [Dynamic colors](https://developer.android.com/develop/ui/views/theming/dynamic-colors), [Core app quality](https://developer.android.com/docs/quality-guidelines/core-app-quality) |
| Text | Line length 45-75 characters per supported language. | Check long locales. | [Core app quality](https://developer.android.com/docs/quality-guidelines/core-app-quality) |
| Layout | Keep primary navigation and key actions in reachable areas; consistent alignment and spacing; move focused inputs above the keyboard. | One-handed test. | [Layout basics](https://developer.android.com/design/ui/mobile/guides/layout-and-content/layout-basics) |
| Permissions | Ask in context when the user starts the related feature; request the minimum (coarse over fine location). If the system says to show a rationale, show an educational UI that can be cancelled; do not block the user or assume system behaviour. Handle denial gracefully. | Deny, deny-again, grant flows. | [Request permissions](https://developer.android.com/training/permissions/requesting), [Core app quality](https://developer.android.com/docs/quality-guidelines/core-app-quality) |
| Notifications | Every notification belongs to a channel (Android 8.0+); users control each channel; after creation you cannot change its behaviour, only name and description. Android 13+ requires the POST_NOTIFICATIONS runtime permission, notifications off by default; ask in context. Persistent only for ongoing events. | One channel per type; permission denied case. | [Channels](https://developer.android.com/develop/ui/views/notifications/channels), [Notification permission](https://developer.android.com/develop/ui/views/notifications/notification-permission) |
| State and speed | Preserve state through back, rotation and process death; show feedback if loading exceeds two seconds. | Kill process, resume from Recents. | [Core app quality](https://developer.android.com/docs/quality-guidelines/core-app-quality) |
| Accessibility | Descriptive labels for interactive elements; decorative images get null descriptions; unique labels in collections. | TalkBack walkthrough. | [Accessibility principles](https://developer.android.com/guide/topics/ui/accessibility/principles) |
| Motion | Use the Material motion system (themed easing, duration and spring slots) and respect the system-wide animation setting: `ValueAnimator.areAnimatorsEnabled()` reports it. | Disable animations in developer settings. | [Material motion (Android docs)](https://github.com/material-components/material-components-android/blob/master/docs/theming/Motion.md), [ValueAnimator](https://developer.android.com/reference/android/animation/ValueAnimator) |

Deeper lookup: [material-3-skill](https://github.com/hamen/material-3-skill) (MIT, Compose-focused); verify numbers on the official pages.
